What Eshveh does

A dating app that plans the first date for you.

Tap through the phone on the left. Everything is black and white, every screen has one clear action, and the two features that set Eshveh apart show up right after a match.

Feature 01

Three spots, halfway

  1. Finds the midpoint between both of you.
  2. Searches Google Places for restaurants and cafés around it.
  3. Keeps only places rated 4.0★ or higher with 50+ reviews, open at your date time.
  4. Asks Google Routes for real travel time from each of you.
  5. Ranks by rating and fairness, then picks 3 different kinds of places.
Feature 02

Three looks, your closet

  1. You photograph each piece once.
  2. Claude tags it: type, color, how dressy, how warm.
  3. Eshveh checks the forecast at the restaurant for the date's hour.
  4. Matches dressiness to the spot: café = casual, bistro = smart, fine dining = upscale.
  5. Builds 3 distinct, complete outfits, adding a coat when it's cold or rainy.
Your launch plan

Eight steps from here to the App Store.

Step 1 is done. The backend and the app code are written and tested. The next steps are mostly accounts and paperwork that need you personally.

01

Build the first version

Backend (Python + FastAPI) and the iPhone/Android app (React Native + Expo).

  • Sign up, profiles, photos, location kept private
  • Discover, likes, matches, chat, block & report
  • Date spots: midpoint + Google Places + Google Routes, 4★+
  • Closet upload + Claude tagging + 3 weather-aware looks
  • App screens: welcome, sign up, 4-step onboarding, swipe deck, match, chat, date spots, closet, looks, profile
  • 15 backend tests passing; app type-checks and builds for iPhone
Done
02

Create your API keys

These let the backend talk to Google and Claude. Each takes about 10 minutes.

  • Google Cloud terms accepted and project "Noir Dating App" created
  • You: click Verify Account in Google Cloud and add your phone number and card (Google requires this; free-trial credit applies)
  • Then Claude enables Places API (New) and Routes API and creates a key restricted to those two
  • Anthropic Console: create an API key for clothing tagging and styling
  • Paste both into the backend's .env file
Needs you
03

Run it on your computer and phone

See the real app working with real places before spending anything on hosting.

  • Install Docker Desktop and Node.js
  • Backend: docker compose up, then open localhost:8000/docs
  • App: npm install then npx expo start, scan the QR code with your phone

06

Safety, privacy and legal

App stores reject dating apps without these, and US rules apply to location and photos.

  • Privacy Policy and Terms of Service (have a lawyer review)
  • Photo moderation and selfie verification
  • Clear 18+ age gate (already in the backend)
  • Check state privacy laws such as California's CCPA and, if you add face checks, Illinois' BIPA
